# Student Management System

## Overview
A small in-memory student record manager using an array of structures.

## Features
Add, display, search, update, delete, and exit. Each student has an ID, name, and marks.

## Concepts
Structures, arrays, functions, linear search, `switch`-style menu decisions, and bounded strings.

## Compile and Run
```text
gcc student-management.c -o student-management
./student-management
```
The records are in memory and reset when the program exits.

## Learning Outcomes
Practice CRUD operations, record searching, and moving the last record into a deleted slot.
