# Bank Management System

## Overview
An educational in-memory account manager, not real banking software.

## Features
Create, display, search, deposit, withdraw, balance inquiry, and exit. Negative deposits and overdrafts are rejected.

## Concepts and Limitations
Uses structures, arrays, functions, validation, and linear search. It has no security, authentication, persistence, encryption, or real banking guarantees.

## Compile and Run
```text
gcc bank-management.c -o bank-management
./bank-management
```

## Learning Outcomes
Practice validation and applying operations to a selected structure record.
