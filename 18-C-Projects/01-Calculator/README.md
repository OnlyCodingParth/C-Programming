# Calculator

## Overview
A menu-driven console calculator for two integers.

## Features
Addition, subtraction, multiplication, division, modulus, repeated calculations, exit, and division-by-zero validation.

## Concepts
Functions, `switch`, loops, input validation, arithmetic, and formatted output.

## Compile and Run
```text
gcc calculator.c -o calculator
./calculator
```
On Windows, run `calculator.exe`.

## Example
Choose `1`, enter `8 4`, and the program displays `Result: 12`.

## Learning Outcomes
Practice decomposing a menu, validating a divisor, and selecting operations with `switch`.
