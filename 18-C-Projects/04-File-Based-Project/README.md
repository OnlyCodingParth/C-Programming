# Contact Management System

## Overview
A beginner file-based project that stores contacts in `contacts.txt`.

## Features
Add contacts, display saved contacts, search by name, and exit. Records are stored as one `name phone` pair per line.

## Concepts
Structures, functions, text files, append mode, reading, searching, and error handling.

## Compile and Run
```text
gcc contact-management.c -o contact-management
./contact-management
```

## Storage Approach
This deliberately simple format is educational and assumes names have no spaces. It is not a production contact database.

## Learning Outcomes
Practice connecting a menu to file operations and searching persisted text records.
