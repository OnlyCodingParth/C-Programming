# C Practice Problems

## 1. Purpose
These standalone programs turn the concepts in the repository into short exercises. Each file has a problem statement and a complete compilable solution.

## 2. Progression
Beginner problems focus on input, conditions, loops, arithmetic, and simple functions. Intermediate problems combine arrays, strings, structures, pointers, sorting, searching, and recursion. Advanced problems add files, dynamic memory, command-line arguments, and multi-step memory reasoning.

## 3. Recommended Order
Solve the beginner folder first, then intermediate, then advanced. Within a folder, increase difficulty gradually and revisit any problem where the reasoning is unclear.

## 4. How to Practice
Read only the comment at the top, write a solution on paper, identify inputs and edge cases, and implement before comparing with the supplied solution. Compile each file independently.

## 5. Debugging and Testing
Use compiler warnings, small known inputs, boundary inputs, invalid inputs, empty or one-element cases, negative values where relevant, and repeated tests. Print temporary state only while debugging, then remove it.

## 6. Complexity
Time complexity describes how work grows with input size; space complexity describes extra memory. A linear search is usually `O(n)`, while binary search is `O(log n)` on sorted data. Nested loops often multiply their costs.

## 7. DSA Preparation
These exercises build the habits needed for data structures and algorithms: invariants, indexing, termination, recursion base cases, memory ownership, and choosing a representation.

## 8. Common Mistakes and Workflow
Watch for off-by-one indexes, unchecked input, division by zero, missing terminators, memory leaks, invalid pointers, and files opened in the wrong mode. A useful workflow is: understand, plan, implement, compile with warnings, test normal and edge cases, then simplify.

## 9. Summary
Practice deliberately from simple control flow toward memory and file problems. Treat every program as a small experiment and verify both its output and its resource handling.
